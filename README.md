# 筋トレ記録アプリ

筋トレの記録（種目、重量、Rep数、メモ）を残して、種目と重量ごとに Rep数の推移をグラフで確認できる Web アプリです。

## 主な機能

- **記録する**: 日付、種目、重量（kg）、Rep数、メモを入力して保存する
- **グラフ**: 種目と重量を選び、日付 − Rep数の折れ線グラフを表示する（同じ日に複数セットある場合は、その日の最大Rep数を表示）
- **履歴**: 記録を新しい順に一覧表示し、1件ずつ削除する

## 使い方

1. このリポジトリをダウンロードする（「Code」→「Download ZIP」で取得し、展開する）
2. `index.html` をブラウザ（Chrome、Edge など）で開く

インストールやサーバーの準備は不要です。

## 注意点

- 記録は**使っているブラウザの中**に保存されます。外部には送られません。
- 別のブラウザや別の端末とは記録を共有できません。いつも同じブラウザで開いてください。
- シークレットモード（InPrivate）で開いたり、ブラウザのサイトデータを削除したりすると、記録が消えます。
- グラフの表示にはインターネット接続が必要です（グラフ用ライブラリ Chart.js をインターネットから読み込むため）。

## 使用技術

HTML / CSS / JavaScript / [Chart.js](https://www.chartjs.org/) 4.4.1 / localStorage
