# 仕様書

| 項目 | 内容 |
|---|---|
| アプリ名 | 筋トレ記録アプリ |
| 作成日 | 2026-10-31 |
| 関連資料 | [技術スタック設計書](tech-stack.md) |

## 1. 目的

筋トレの記録（種目、重量、Rep数、メモ）を残し、種目と重量ごとに Rep数の推移をグラフで確認できるようにする。

## 2. 前提

- 利用者は1人で、1台の端末・1つのブラウザで使う
- データは利用者のブラウザ内に保存し、外部には送らない
- 重量の単位は kg とする

## 3. 要件

### 3.1 当初の要件

| No. | 要件 |
|---|---|
| R1 | 種目、重量、Rep数、メモ（自由記述）を入力できること |
| R2 | 種目、重量を選択し、日付 − Rep数のグラフを表示できること |

### 3.2 実装時に追加した仕様

| No. | 内容 | 理由 |
|---|---|---|
| A1 | 記録に「日付」を入力できる（初期値は今日） | グラフの横軸に日付が必要なため |
| A2 | 過去に入力した種目を入力候補として表示する | 同じ種目を何度も入力する手間を減らすため |
| A3 | 記録の履歴を一覧表示し、1件ずつ削除できる | 入力ミスを直せるようにするため |
| A4 | 同じ日・同じ種目・同じ重量の記録が複数ある場合、グラフにはその日の最大Rep数を表示する | 1日に複数セット行うことが多いため |

## 4. 画面構成

画面は1ページで、上から次の3つの区画が並ぶ。

```
┌─────────────────────────┐
│ 筋トレ記録アプリ（ヘッダー）    │
├─────────────────────────┤
│ ① 記録する                  │
│   日付 / 種目 / 重量 / Rep数  │
│   メモ / [保存]              │
├─────────────────────────┤
│ ② グラフ（日付 − Rep数）      │
│   種目 [▼]  重量 [▼]          │
│   （折れ線グラフ）             │
├─────────────────────────┤
│ ③ 履歴                      │
│   ベンチプレス 60kg × 10回 [削除] │
│   …                         │
└─────────────────────────┘
```

## 5. 機能詳細

### 5.1 記録する

| 入力項目 | 必須 | 入力形式 | 入力できる値 | 初期値 |
|---|---|---|---|---|
| 日付 | ○ | 日付選択 | 任意の日付 | 今日 |
| 種目 | ○ | 文字入力（過去の種目を候補表示） | 任意の文字（前後の空白は削除） | 空 |
| 重量 (kg) | ○ | 数値 | 0 以上、0.5 刻み | 空 |
| Rep数 | ○ | 数値 | 1 以上の整数 | 空 |
| メモ | − | 複数行の文字入力 | 任意の文字（前後の空白は削除） | 空 |

**保存ボタンを押したときの動作**

1. 必須項目が空、または入力できる値の範囲外の場合は保存しない（ブラウザが入力欄にメッセージを表示する）
2. 記録を1件追加し、ブラウザに保存する
3. 同じ種目・重量で続けて入力しやすいよう、**Rep数とメモだけを空にする**（日付、種目、重量は残す）
4. Rep数の入力欄にカーソルを移す
5. グラフの選択欄を、保存した記録の種目・重量に切り替える
6. 種目の入力候補、グラフ、履歴を最新の状態にする

### 5.2 グラフ

**選択欄**

| 選択欄 | 選択肢 |
|---|---|
| 種目 | 記録のあるすべての種目（名前順） |
| 重量 | 選択中の種目で記録のある重量（軽い順） |

- 種目を切り替えると、重量の選択肢もその種目のものに切り替わる
- 切り替え前の重量が新しい種目にもある場合は、その重量を選んだままにする

**グラフの内容**

| 項目 | 内容 |
|---|---|
| 種類 | 折れ線グラフ |
| 横軸 | 日付（古い順） |
| 縦軸 | Rep数（0 から始まる、目盛りは整数） |
| 表示する値 | 選んだ種目・重量の記録のうち、日付ごとの最大Rep数 |
| 凡例 | 「{種目} {重量}kg の Rep数」 |

- 記録が1件もない場合は、グラフの代わりに「記録がありません」と表示する

### 5.3 履歴

- すべての記録を、**日付の新しい順**に表示する（同じ日付の場合は、後から入力したものが上）
- 1件ごとに次の内容を表示する
  - 1行目: `{種目}  {重量}kg × {Rep数}回`
  - 2行目: 日付
  - 3行目以降: メモ（入力した場合のみ。改行もそのまま表示）
- 「削除」ボタンを押すと確認メッセージを表示し、「OK」を選ぶとその記録を削除する。削除後はグラフと履歴を最新の状態にする
- 記録が1件もない場合は「記録がありません」と表示する

## 6. データ項目

記録1件は次の項目を持つ。

| 項目名 | 内容 | 型 | 例 |
|---|---|---|---|
| id | 記録を見分けるための番号（保存した時刻のミリ秒） | 数値 | 1793404800000 |
| date | 日付（YYYY-MM-DD 形式） | 文字列 | "2026-10-31" |
| exercise | 種目 | 文字列 | "ベンチプレス" |
| weight | 重量（kg） | 数値 | 60 |
| reps | Rep数 | 数値 | 10 |
| memo | メモ（未入力の場合は空文字） | 文字列 | "フォーム良好" |

**保存場所**: ブラウザの localStorage（キー: `workout-records`）に、記録の配列を JSON 形式で保存する。

```json
[
  {
    "id": 1793404800000,
    "date": "2026-10-31",
    "exercise": "ベンチプレス",
    "weight": 60,
    "reps": 10,
    "memo": "フォーム良好"
  }
]
```

## 7. 制約

- 別のブラウザ・別の端末とはデータを共有できない（詳細は [技術スタック設計書](tech-stack.md) の「7. 制約と注意点」を参照）
- オフラインではグラフが表示されない（記録の入力と履歴は使える）
- 記録の編集機能はない（直したい場合は削除してから入力し直す）
- データのバックアップ機能はない

## 8. 今後の検討事項

| 内容 | 優先度の目安 |
|---|---|
| データの書き出し・読み込み（バックアップ、ブラウザ間の引っ越し） | 高 |
| 記録の編集 | 中 |
| オフラインでもグラフを表示する | 中 |
| 推定1RM や総挙上量（重量 × Rep数）のグラフ | 低 |
| PCとスマホでのデータ共有（クラウドのデータベース） | 低 |
